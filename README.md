# Наш семейный альбом

Хронология жизни семьи в фотографиях и видео: единое место, куда складываются снимки,
и где их легко найти спустя годы — по человеку, по году, по событию.

Продукт состоит из двух частей: веб-приложение с общим хранилищем, куда приходят родные,
и набор локальных инструментов, которые разбирают архив перед загрузкой.

## Витрина

**[Открыть витрину](https://baliyakenzhe-code.github.io/family-album/)** — десять снимков
из архива, чтобы показать устройство альбома: разделы, годы, поиск, полноэкранный просмотр.
Собирается скриптом [`make-site.pl`](make-site.pl) из [`index.html`](index.html), работает
где угодно и ни от чего не зависит.

## Приложение

[`app.html`](app.html) — самодостаточная страница без сборки и фреймворков.
Опубликована как артефакт Claude: фотографии лежат в общем хранилище, изменения одного
члена семьи сразу видны остальным. Разделы, модель данных и ограничения описаны в [PRD.md](PRD.md).

Открывать этот файл как обычную веб-страницу бессмысленно: хранилище ему даёт среда Claude,
и без неё он показывает заглушку вместо фотографий. Именно поэтому витрина сделана отдельно.

## Инструменты разбора

Все скрипты работают на штатном macOS: метаданные берутся из `sips` и `mdls`,
конвертация — тоже `sips`. Ставить ничего не нужно, нужен только perl.

### `sort-album.pl` — раскладывает архив

Сгружаете всё в одну папку, скрипт раскладывает по годам, событиям и путешествиям.

```
perl sort-album.pl                  предпросмотр, ничего не меняет
perl sort-album.pl --apply          разложить копии по папкам
perl sort-album.pl --apply --jpeg   плюс JPEG-копии для HEIC
```

Как он решает:

- **Дата** — из EXIF. Если камера её не записала, пробует достать из имени файла:
  у дронов DJI и снимков из мессенджеров дата часто живёт только там.
- **Событие** — новая папка начинается после паузы в 6 часов или смещения на 25 км.
- **Путешествие** — по расстоянию от «своих мест». Свои места определяются сами:
  это точки, куда возвращаются годами. Одна долгая поездка так не выглядит и остаётся
  путешествием, а регулярные визиты в другой город — нет.
- **Дубликаты** — по содержимому файла, а не по имени.

Дату из файловой системы скрипт намеренно не использует: у картинок без EXIF это дата
появления файла на диске, и тогда сотни скачанных изображений склеиваются в одно «событие».

### `people.pl` — папки по людям

```
perl people.pl --sheet    собрать контактный лист
perl people.pl --apply    разложить по папке «Люди»
```

`--sheet` собирает миниатюры всех папок в одну картинку — по ней удобно разметить,
кто где, не открывая снимки по одному. Разметка живёт в `люди.txt`.
Папки по людям делаются жёсткими ссылками, поэтому не занимают места на диске.

### `upload-prep.pl` — подготовка к заливке

Уменьшает фотографии до 1900 px и собирает метаданные (раздел, год, подпись) в JSON
для загрузки в приложение.

## Что здесь не лежит

Сам архив в репозиторий не попадает — только десяток снимков в `примеры/` для наглядности.
Не публикуется и `manifest.csv`: в нём GPS-координаты съёмок, включая домашние.
